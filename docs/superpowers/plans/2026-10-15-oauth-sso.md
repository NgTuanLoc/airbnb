# OAuth Sign-in and Enterprise SSO — Implementation Plan

**Spec:** `docs/superpowers/specs/2026-10-15-oauth-sso-design.md`
**Workflow:** test first for each task: failing test → minimal implementation → passing test → commit.

Backend commands run from `backend/`; frontend commands from `frontend/`.

## Task 1 — Envelope `code` and ServiceDefaults retries

**Files:**
- `backend/src/Airbnb.SharedKernel/ApiResponse.cs`: add an optional `Code`, omitted when null, and `ApiResponse.Fail(error, code = null)`.
- `backend/src/Airbnb.ServiceDefaults/Extensions.cs`: the standard resilience handler with `Retry.DisableForUnsafeHttpMethods()`.
- `backend/tests/Airbnb.UnitTests/SharedKernel/ApiResponseTests.cs`: a failure with a code serialises it, one without stays byte-for-byte the same.

## Task 2 — Data model and migration

**Files:**
- `User.cs`: `PasswordHash` nullable; `EmailVerifiedAt`.
- New `External/ExternalLogin.cs` and `External/ExternalLoginFlow.cs`.
- `Data/IdentityDbContext.cs`: the two tables and their keys and indexes.
- Migration `ExternalLogins`: `dotnet tool restore`, then `dotnet ef migrations add ExternalLogins --project src/Modules/Identity/Airbnb.Modules.Identity --startup-project src/Modules/Identity/Airbnb.Modules.Identity --output-dir Data/Migrations`.
- `Login.cs`: a password-less account runs the dummy hash.

**Test:** `AuthEndpointTests` (password login on a password-less account → the same 401).

## Task 3 — Options, PKCE, providers

**Files (all in `Airbnb.Modules.Identity/External/`):**
- `ExternalLoginOptions.cs`: binding, validation, enabled providers, SSO by domain.
- `Pkce.cs`: verifier, challenge and random values.
- `ExternalIdentity.cs`: the record a provider returns.
- `IExternalProvider.cs`: `BuildAuthorizationUrl(flow, redirectUri, loginHint)` and `ExchangeAsync(code, flow, redirectUri, iss)`.
- `OidcProvider.cs`: Google and SSO, with a `ConfigurationManager`, `JsonWebTokenHandler` and a factory-backed `IDocumentRetriever`.
- `GitHubProvider.cs`.
- `ExternalProviders.cs`: a registry built from the options; keys `google`, `github`, `sso-<id>`.

**Packages:** `Microsoft.IdentityModel.Protocols.OpenIdConnect` and `Microsoft.IdentityModel.JsonWebTokens` 8.23.0 in `Directory.Packages.props`.

**Unit tests** (`tests/Airbnb.UnitTests/Identity/`):
- PKCE (the RFC 7636 vector);
- options validation and domain lookup;
- authorization URL parameters;
- ID token validation;
- GitHub email choice.

## Task 4 — Endpoints and linking rules

**Files (in `External/`):**
- `ListProviders.cs`;
- `StartExternalLogin.cs`;
- `CompleteExternalLogin.cs`, with a pure `AccountLinking.Decide(...)`;
- `ListConnections.cs`;
- `RemoveConnection.cs`.

Wire them into `IdentityModule` (services, named `HttpClient`, options, endpoints).

**Tests:**
- `tests/Airbnb.Api.Tests/Identity/FakeIdentityProvider.cs`: discovery, JWKS, token endpoint, GitHub API.
- `ExternalLoginTests.cs`: every row of the spec's endpoint table and callback rules.
- `tests/Airbnb.UnitTests/Identity/AccountLinkingTests.cs`.

## Task 5 — Aspire

**Files:**
- `Directory.Packages.props`: `Aspire.Hosting.Keycloak` 13.6.1-preview.1.26506.6 (written against 13.5.4-preview.1.26464.4; moved with the Aspire 13.6.1 upgrade).
- `src/Airbnb.AppHost/Realms/acme-realm.json`: client `airbnb` (secret placeholder), users `alex@acme.test` and `sam@acme.test`.
- `AppHost.cs`:
  - Keycloak and the secret parameter;
  - the API's `Identity__External__*` settings from the frontend and Keycloak endpoints;
  - optional Google/GitHub from configuration.
- `tests/Airbnb.AppHost.Tests/AppHostSmokeTests.cs`: wait for Keycloak; SSO start returns a Keycloak URL that serves a login page.
